      How to use yourNotes

      Writing

      • The text box grows as you type.
      • + starts a new empty note. If the current note has unsaved changes, you are asked first.
      • An asterisk (*) in the window title means unsaved changes.
      • Close appears while you read an open note. It closes the note and leaves an empty editor.

      Read and edit

      • Click a note name in the list to open it in read mode (read-only text).
      • The eye icon next to a note opens it in a read-only window.
      • The pencil icon opens the note in edit mode.
      • In the editor, switch between read and edit mode with ⌘E.

      Saving and folders

      • The arrow button (save) opens the save window.
      • Choose a folder with Choose…. Folders need Chrome or Edge. Other browsers download the file.
      • New folder creates a subfolder inside the current folder and saves there from then on.
      • Type a name in Name. If you leave out the extension, .txt is added.
      • Open file… opens a file from your computer, in any browser.

      Passwords

      • The lock note button sets, changes or removes the password of the current note.
      • The password is applied when you save. Protected notes are saved encrypted.
      • Opening a protected note, or deleting one, asks for its password first.
      • There is no password recovery. If you forget the password, the note cannot be read.

      Notes list

      • The search box filters the notes in the current folder by name or tag.
      • Write a word starting with # anywhere in a note to tag it, like #work.
      • Type # and a tag in the search box to list only the notes with that tag.
      • Protected notes are listed without tags, so tag search skips them.
      • The × button deletes a note after you confirm.
      • The note that is open is marked with a pulsing dot.

      Shortcuts

      • ⌘N new note
      • ⌘S save
      • ⇧⌘S open the save window
      • ⌘E switch read and edit mode
      • ⌘Enter save from inside the editor
      • Esc close the open window
