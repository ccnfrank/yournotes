      How to use yourNotes

      Creating notes

      • The text box in the editor is where you write. It is as tall as the list of notes, up to 400 px.
      • Press + (or ⌘N) to start a new empty note. If the current note has unsaved changes, you are asked first.
      • A new note has no file yet. Save it to give it a name and a place in a folder.

      Saving and folders

      • Choose a folder with Folder… in the notes list, or with Choose… in the save window. Folders need Chrome or Edge. Other browsers download the file instead.
      • Press the save arrow (or ⌘S) to save into the folder. ⇧⌘S opens the save window, where you can pick the folder and the name.
      • Type a name in Name. If you leave out the extension, .txt is added. The app reads and writes .txt, .md, .text and .log files.
      • New folder creates a subfolder inside the current folder and saves there from then on.
      • Open file… opens a text file from your computer, in any browser.
      • Once a note has a file in the folder, it is saved automatically one second after you stop typing, while the note is in edit mode.

      Viewing and editing

      • Click a note's row in the list to open it in read mode. Read mode shows the text without allowing changes.
      • The eye icon, captioned view, opens the note in a read-only window. Close it with close or Esc.
      • The pencil icon, captioned edit, opens the note in edit mode.
      • In the editor, switch between read and edit mode with ⌘E.
      • The close button in the editor closes the current note and leaves an empty editor. If there are unsaved changes, you are asked first.

      Renaming

      • Click a note's name in the list to rename it. Type the new name and press Enter to confirm, or Esc to cancel. Clicking anywhere else also cancels.
      • A name without an extension gets .txt. Only .txt, .md, .text and .log are allowed.
      • If a file with the new name already exists, the rename is refused.
      • If the note is open in the editor, it stays open under the new name. Its links in the graph follow the new name.

      Deleting

      • The trash it button, the × on the right of each row, deletes the note after you confirm. This cannot be undone.
      • In graph view, click a point to select it, then press Delete to delete that note after you confirm.
      • Deleting a protected note asks for its password first.
      • The links that involved a deleted note are removed from links.json.

      Undo

      • The undo button, to the right of lock note, takes back your last changes in the editor. It goes back up to 10 changes.
      • Typing is grouped: a pause of one second separates one change from the next, so one undo takes back a whole phrase, not a single letter.
      • Undo works in edit mode only. Opening, creating or closing a note clears the undo history.

      Passwords

      • The lock note button sets, changes or removes the password of the current note.
      • The password is applied when the note is saved. Protected notes are saved encrypted.
      • Opening a protected note, or deleting one, asks for its password first. A wrong password is refused.
      • To remove the password, open lock note and choose Remove. The note is then saved as plain text.
      • There is no password recovery. If you forget the password, the note cannot be read.
      • Protected notes are listed without tags and without links from their text, so they do not take part in tag or mention links.

      Search

      • The search box above the list filters the notes in the current folder by name or tag.
      • Without #, the search matches names and tags, so work finds notes named work and notes tagged #work.
      • With #, the search matches only tags: #wo finds #work.
      • In graph view the same search is in a window: press ⌘F on a Mac, or Alt+F on Windows and Linux. See Graph view mode.

      Tags

      • To tag a note, write a word starting with # anywhere in its text, like #work or #ideia-2. Tags can use letters, numbers, - and _.
      • A # followed by a space or a number is not a tag, so # title and #1 are ignored.
      • Tags are not case sensitive: #Work and #work are the same tag.
      • A note can have as many tags as you like.

      Links between notes

      • Shared tags: notes that have at least one tag in common are linked automatically.
      • Mentions: when a note's text contains the name of another note, the two are linked. For example, a note that says see b is linked to b.txt. The name is not case sensitive, the extension is optional, and it must be a whole word.
      • A note that mentions several notes is linked to all of them.
      • Manual links: in graph view, hold Shift and click one point, then another, to link them. Shift + click the same pair again to remove the link.
      • Manual links are saved in a file called links.json inside the folder, next to the notes. Automatic links are not saved; they come from the tags and the text.
      • A common word can be a note name too. For example, a note named a is mentioned by any text with the word a. Name short notes with care.
      • To remove a link that came from a tag or a mention, change the tag or the text. Shift + click removes manual links only.

      New in version 0.3

      Graph view mode

      • Click Graph view mode, next to Folder…, to see the notes as a web. Each note is a point, and linked points are joined by lines.
      • Lines in a brighter colour are manual links. The others come from shared tags or mentions.
      • Drag a point to move it. The web rearranges itself around it. Points are kept out of the search window and the zoom bar.
      • Click a point, or the name next to it, to read the note in a read-only window. The web stays open.
      • Shift + click one point, then another, to link them, as described in Links between notes.
      • When the graph opens, the notes are centred in the window at 150%.
      • Zoom with the mouse wheel, centred on the cursor, or with the slider under the top bar. The percentage shows the current zoom.
      • fit to window, next to the slider, zooms and centres the graph so that all the notes fit in the window.
      • Hold the right mouse button and drag to move the whole web around.
      • Press ⌘F on a Mac, or Alt+F on Windows and Linux, to open the search window. Notes that match stay bright and the others are dimmed. Press Esc to close the window. The search stays active until you clear it.
      • Select a point by clicking it, then press Delete to delete that note after you confirm.
      • Click Back to editor view at the top to return to the list and the editor.

      Themes

      • The switch in the top-right corner changes between night and day. Your choice is remembered.

      Shortcuts

      • ⌘N new note
      • ⌘S save
      • ⇧⌘S open the save window
      • ⌘E switch read and edit mode
      • ⌘Enter save from inside the editor
      • ⌘F (Mac) or Alt+F (Windows and Linux): open the search window, in graph view
      • Delete: delete the selected note, in graph view
      • Enter confirm a rename; Esc cancel it
      • Esc close the open window, or the graph search
