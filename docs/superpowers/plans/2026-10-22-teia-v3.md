# yourNotes v3: teia de notas — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar `editor/v3/`, uma versão do yourNotes em que as notas de uma pasta aparecem como pontos numa teia, com ligações automáticas por tag e ligações manuais guardadas em `links.json`.

**Architecture:** Lógica pura (tags, ligações, formato de `links.json`) em `links.js`, testável no Node. Simulação de forças em `graph.js`, também sem DOM. `app.js` (copiado e adaptado da v2) faz carregamento, gravação, eventos e ligação com o canvas. `index.html` e `style.css` são copiados da v2 e recebem o canvas em tela cheia.

**Tech Stack:** HTML, CSS e JavaScript puros, sem dependências. Testes com `node:test` (built-in do Node 18+).

**Spec:** `editor/docs/superpowers/specs/2026-10-22-teia-v3-design.md`

## Global Constraints

- Sem dependências externas; nada de bundler, npm ou framework.
- Não alterar nada em `editor/v2/`.
- `links.json` usa `"version": 1` e pares `[a, b]` ordenados alfabeticamente, sem repetição.
- Notas protegidas (`ENCRYPTED-NOTE:v1\n`) nunca têm tags lidas.
- Extensões de notas: `.txt`, `.md`, `.text`, `.log`.
- Regra de tag: `/(^|\s)#(\p{L}[\p{L}\p{N}_-]*)/gu`, minúscula.
- Não há repositório git em `editor/`: os passos de commit não se aplicam; o usuário revisa os arquivos diretamente.

## Review Focus

- `links.json` corrompido ou com JSON inválido: tratado como vazio, sem apagar o arquivo antes de uma nova ligação. (Task 1)
- Ligação apontando para nota apagada fora do app: ignorada ao carregar e removida na próxima gravação. (Task 1, Task 4)
- Renomear nota pelo app com ligações existentes: pares atualizados antes de gravar. (Task 4)
- Falha ao gravar `links.json` (permissão negada): mensagem de erro, ligação continua na tela. (Task 4)
- Pasta com centenas de notas: simulação não trava; limite de iterações por quadro. (Task 2)

### Task 1: Lógica pura de ligações e `links.json`

**Files:**
- Create: `editor/v3/links.js`
- Test: `editor/v3/tests/links.test.mjs`

**Interfaces:**
- Consumes: nada.
- Produces (exportados via `module.exports` e também global `window.Links` no navegador):
  - `extractTags(text: string) -> string[]` — tags em minúsculas, ordenadas, sem repetição.
  - `automaticLinks(notes: {name: string, tags: string[]}[]) -> [string, string][]` — pares de notas com pelo menos uma tag em comum; pares ordenados.
  - `normalizeLinks(list: any, existingNames: Set<string>) -> [string, string][]` — aceita o conteúdo de `links.json` já parseado (ou `null`/lixo); devolve pares válidos, ordenados, sem repetição, só com nomes em `existingNames`.
  - `parseLinksFile(text: string) -> { links: [string,string][], error: string|null }` — JSON inválido devolve `links: []` e `error` com mensagem.
  - `serializeLinks(links: [string,string][]) -> string` — JSON com `version: 1`, pares normalizados.
  - `toggleLink(links: [string,string][], a: string, b: string) -> [string,string][]` — adiciona o par se ausente, remove se presente; nunca devolve o par com `a === b`.

```js
// editor/v3/tests/links.test.mjs
import { test } from 'node:test';
import assert from 'node:assert/strict';
import Links from '../links.js';

test('extractTags ignora # seguido de espaço ou número e normaliza para minúsculas', () => {
  assert.deepEqual(Links.extractTags('# título #Work #1 #ideia-2'), ['ideia-2', 'work']);
});

test('automaticLinks liga notas com tag em comum, sem auto-ligação', () => {
  const notes = [
    { name: 'a.txt', tags: ['work'] },
    { name: 'b.txt', tags: ['work', 'x'] },
    { name: 'c.txt', tags: [] },
  ];
  assert.deepEqual(Links.automaticLinks(notes), [['a.txt', 'b.txt']]);
});

test('normalizeLinks ordena, remove repetidos e nomes inexistentes', () => {
  const names = new Set(['a.txt', 'b.txt']);
  assert.deepEqual(
    Links.normalizeLinks([['b.txt', 'a.txt'], ['a.txt', 'b.txt'], ['a.txt', 'gone.txt'], 'lixo'], names),
    [['a.txt', 'b.txt']],
  );
});

test('parseLinksFile trata JSON inválido como vazio com erro', () => {
  const r = Links.parseLinksFile('{não é json');
  assert.deepEqual(r.links, []);
  assert.ok(r.error);
});

test('serializeLinks grava version 1 e pares ordenados', () => {
  const text = Links.serializeLinks([['b.txt', 'a.txt']]);
  assert.deepEqual(JSON.parse(text), { version: 1, links: [['a.txt', 'b.txt']] });
});

test('toggleLink adiciona e remove o mesmo par, em qualquer ordem', () => {
  let links = Links.toggleLink([], 'b.txt', 'a.txt');
  assert.deepEqual(links, [['a.txt', 'b.txt']]);
  links = Links.toggleLink(links, 'a.txt', 'b.txt');
  assert.deepEqual(links, []);
});

test('toggleLink ignora auto-ligação', () => {
  assert.deepEqual(Links.toggleLink([], 'a.txt', 'a.txt'), []);
});
```

### Task 2: Simulação de forças em `graph.js`

**Files:**
- Create: `editor/v3/graph.js`
- Test: `editor/v3/tests/graph.test.mjs`

**Interfaces:**
- Consumes: `nodes` e `links` no formato da Task 1 (nomes de nota).
- Produces (mesma estratégia de exportação da Task 1, global `window.Graph`):
  - `createSimulation(nodeNames: string[], links: [string,string][], width: number, height: number) -> Sim`
  - `Sim` é um objeto com:
    - `nodes: { name: string, x: number, y: number, vx: number, vy: number, fixed: boolean }[]`
    - `setLinks(links: [string,string][]) -> void` — troca as ligações sem resetar posições.
    - `step() -> void` — uma iteração: repulsão entre todos, mola entre ligados, atração leve ao centro, amortecimento.
    - `settle(maxSteps: number) -> number` — roda `step` até a energia cair abaixo de um limite ou atingir `maxSteps`; devolve as iterações feitas.
    - `pinAt(name: string, x: number, y: number) -> void` e `release(name: string) -> void` — usados ao arrastar.
  - Constantes: `maxSteps` padrão 300 por quadro de `settle`; repulsão quadrática com corte para não explodir com muitos pontos.

- [ ] **Step 1: Escrever os testes que falham**

```js
// editor/v3/tests/graph.test.mjs
import { test } from 'node:test';
import assert from 'node:assert/strict';
import Graph from '../graph.js';

const dist = (a, b) => Math.hypot(a.x - b.x, a.y - b.y);

test('nós ligados ficam mais perto que nós sem ligação', () => {
  const sim = Graph.createSimulation(['a', 'b', 'c'], [['a', 'b']], 800, 600);
  sim.settle(500);
  const byName = Object.fromEntries(sim.nodes.map(n => [n.name, n]));
  assert.ok(dist(byName.a, byName.b) < dist(byName.a, byName.c));
});

test('posições ficam finitas com muitos nós', () => {
  const names = Array.from({ length: 300 }, (_, i) => `n${i}.txt`);
  const links = names.slice(1).map((n, i) => [names[i], n]);
  const sim = Graph.createSimulation(names, links, 1000, 800);
  const iterations = sim.settle(300);
  assert.ok(iterations <= 300);
  for (const n of sim.nodes) {
    assert.ok(Number.isFinite(n.x) && Number.isFinite(n.y));
  }
});

test('nó fixado não se move na simulação', () => {
  const sim = Graph.createSimulation(['a', 'b'], [['a', 'b']], 800, 600);
  sim.pinAt('a', 100, 100);
  sim.settle(200);
  const a = sim.nodes.find(n => n.name === 'a');
  assert.equal(a.x, 100);
  assert.equal(a.y, 100);
});
```
